# PrepAI — AI Interview Prep

An AI-powered mock interview platform built with **Next.js 15** and **Firebase**. Practice real, voice-based job interviews with an AI agent, get your questions generated by Google Gemini, and receive detailed, structured feedback on your performance.

**Live demo:** [https://ai-interview-prep-mohit.vercel.app/](https://ai-interview-prep-mohit.vercel.app/)

---

## Features

- **Voice-based AI interviews** — Talk to an AI interviewer in real time using [Vapi](https://vapi.ai) voice agents. The agent asks your generated questions, listens to your answers, and transcribes the conversation live.
- **AI-generated interview questions** — Google **Gemini 2.0 Flash** (via the Vercel AI SDK) generates a tailored question set from your target role, experience level, tech stack, question type (technical/behavioural), and question count.
- **Structured AI feedback** — After each interview, the full transcript is analyzed by Gemini and scored (0–100) across five categories: Communication Skills, Technical Knowledge, Problem-Solving, Cultural & Role Fit, and Confidence & Clarity — plus strengths, areas for improvement, and a final assessment.
- **Authentication with session cookies** — Email/password sign-up and sign-in via Firebase Auth, with secure server-side session cookies (1-week duration, httpOnly).
- **Interview dashboard** — See your past interviews and interviews available to take, rendered as cards with tech-stack icons, cover images, and feedback scores.
- **Modern UI** — Tailwind CSS 4, shadcn/ui (Radix primitives), dark theme, toast notifications (sonner), and forms built with React Hook Form + Zod validation.

## Getting Started

### Prerequisites

- Node.js 18+
- A [Firebase](https://firebase.google.com) project with Authentication (Email/Password) and Firestore enabled
- A [Vapi](https://vapi.ai) account (web token + workflow)
- A [Google AI Studio](https://aistudio.google.com) API key for Gemini

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/moohiit/ai-interview-prep.git
   cd ai-interview-prep
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Create a `.env.local` file in the project root:
   ```env
   # Firebase client SDK (Project settings → General → Your apps)
   NEXT_PUBLIC_FIREBASE_API_KEY=your_firebase_api_key
   NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=your_project.firebaseapp.com
   NEXT_PUBLIC_FIREBASE_PROJECT_ID=your_project_id
   NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=your_project.appspot.com
   NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=your_sender_id
   NEXT_PUBLIC_FIREBASE_APP_ID=your_app_id
   NEXT_PUBLIC_FIREBASE_MEASUREMENT_ID=your_measurement_id

   # Firebase Admin SDK (Project settings → Service accounts)
   FIREBASE_PROJECT_ID=your_project_id
   FIREBASE_CLIENT_EMAIL=firebase-adminsdk-xxxxx@your_project.iam.gserviceaccount.com
   FIREBASE_PRIVATE_KEY="-----BEGIN PRIVATE KEY-----\n...\n-----END PRIVATE KEY-----\n"

   # Vapi voice agent
   NEXT_PUBLIC_VAPI_WEB_TOKEN=your_vapi_web_token
   NEXT_PUBLIC_VAPI_WORKFLOW_ID=your_vapi_workflow_id

   # Google Gemini (Vercel AI SDK)
   GOOGLE_GENERATIVE_AI_API_KEY=your_gemini_api_key
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```

5. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Routes & API

| Route | Access | Description |
|---|---|---|
| `/` | Authenticated | Dashboard — your interviews and available interviews |
| `/sign-in` | Public | Sign in |
| `/sign-up` | Public | Create an account |
| `/interview` | Authenticated | Generate a new interview via the voice agent |
| `/interview/[id]` | Authenticated | Take a voice interview session |
| `/interview/[id]/feedback` | Authenticated | View AI-generated feedback and scores |
| `GET /api/vapi/generate` | Public | Health-check endpoint |
| `POST /api/vapi/generate` | Public | Generate interview questions with Gemini and store the interview in Firestore. Body: `{ type, role, level, techstack, amount, userid }` |

Server-side data operations (auth/session, fetching interviews, creating feedback) are implemented as Next.js **Server Actions** in `lib/actions/`.

## How the AI Pipeline Works

1. **Generate** — You describe the role, level, tech stack, and question mix; Gemini 2.0 Flash produces a clean question list and the interview is saved to Firestore.
2. **Interview** — The Vapi voice agent conducts the interview using those questions, streaming a live transcript to the UI.
3. **Feedback** — The transcript is passed to Gemini with a structured Zod schema, producing category scores, strengths, weaknesses, and a final assessment stored in Firestore.
